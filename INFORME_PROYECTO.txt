DESCRIPCIÓN DEL PROYECTO
═══════════════════════════════════════════════════════════════════════════════════

El proyecto consiste en una aplicación web completa para generar códigos QR destinados
a la publicación y distribución de cursos de reducción de puntos del carnet de conducir.

🎯 OBJETIVO PRINCIPAL:
Facilitar la distribución de materiales educativos para cursos de recuperación de
puntos mediante códigos QR que pueden ser escaneados desde dispositivos móviles.

🔧 FUNCIONALIDADES IMPLEMENTADAS:
• Generación de códigos QR desde URLs web
• Generación de códigos QR desde archivos subidos (PDF, DOC, DOCX, JPG, PNG)
• Interfaz web responsiva y moderna
• Descarga directa de códigos QR generados
• Gestión de nombres de cursos
• Sistema de validación de URLs y archivos

   - Documentación completa en DEPLOY.md

❌ PROBLEMA 3: Archivos no accesibles públicamente
✅ SOLUCIÓN: URLs públicas para archivos subidos
   - Sistema de URL base configurable
   - Detección automática de entorno
   - Servido estático de archivos uploads

═══════════════════════════════════════════════════════════════════════════════════
ENDPOINTS DE LA API
═══════════════════════════════════════════════════════════════════════════════════

🌐 RUTAS PRINCIPALES:
GET  / 
     └── Página principal de la aplicación

GET  /api/config
     └── Información de configuración y debugging
     └── Retorna: baseUrl, host, headers, environment

POST /generate-qr-url
     └── Genera QR desde URL
     └── Body: { url: string, courseName?: string }
     └── Retorna: { success, qrCode, url, courseName }

POST /generate-qr-file
     └── Genera QR desde archivo subido
     └── FormData: file, courseName?
     └── Retorna: { success, qrCode, fileUrl, fileName, courseName }

GET  /uploads/:filename
     └── Descarga de archivos subidos

GET  /qr-codes/:filename
     └── Descarga de códigos QR generados

MÉTRICAS Y RENDIMIENTO
═══════════════════════════════════════════════════════════════════════════════════

⚡ RENDIMIENTO:
• Generación QR: ~100-200ms por código
• Tamaño QR: 300x300px, ~5-15KB por imagen
• Límite archivos: 10MB máximo
• Formatos soportados: PDF, DOC, DOCX, JPG, PNG
• Concurrent requests: Limitado por Express (sin configuración específica)

📊 CAPACIDADES:
• Almacenamiento: Limitado por disco local
• Memoria: Optimizado para ~1GB RAM
• Escalabilidad: Horizontal via load balancer
• Disponibilidad: 99% mientras VS Code esté activo
